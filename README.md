# Pigeon Pitch, One Line

Coo delivers lunch scraps by pigeon — 40,000 birds, under four minutes, and the tip gets eaten, not tipped. One pigeon, one pitch, one line.

## How to run

```sh
python3 main.py
```

That saves the 146-character pitch as UTF-8 to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output/entry.txt`). It uses only the Python standard library, makes no network calls, and produces identical output on every run.
